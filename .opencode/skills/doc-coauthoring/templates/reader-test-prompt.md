# Reader test prompt

Use this in a fresh context with only the document content attached or pasted.

## Prompt
You are reviewing a document with no background from the authoring conversation.
Read the document and answer the following:

1. Summarize the proposal or decision in 3-5 bullets.
2. What is the main problem the document is trying to solve?
3. What assumptions does the document expect readers to already know?
4. What questions would a skeptical reviewer ask next?
5. Which decisions are explicit, and which are only implied?
6. What parts are ambiguous, missing, or internally inconsistent?
7. If you had to implement or approve this, what else would you need?

## How to use the results
- Fix gaps where the reviewer misunderstood the goal or approach.
- Add missing definitions, links, or examples where assumptions were hidden.
- Remove redundant sections that did not help the reviewer answer the questions.
